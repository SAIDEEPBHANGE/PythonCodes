# Python Basics

Start here to learn Python syntax, data types, branching, loops, functions, and exceptions. These examples use Python 3 and the standard library.

## Examples

- [Basic syntax](Basic%20Syntax.py)
- [Variables and data types](Variables%20and%20Data%20Types.py)
- [Conditionals](Conditionals.py)
- [Type casting](TypeCasting.py)
- [Exceptions](Exceptions.py)
- [Functions and built-in functions](FunctionsBuiltinFunctions.py)
- [Loops](Loops.py)

From the repository root, run an example with:

```bash
python "basics/Exceptions.py"
```

The exceptions example deliberately triggers and catches several errors. Read an example before running it; some examples may request input.
