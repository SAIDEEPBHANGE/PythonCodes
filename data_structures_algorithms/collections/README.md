# Python Collections

Learn the built-in collection types and how they differ. These examples require Python 3.

- [Lists](Lists.py): ordered, mutable sequences.
- [Tuples](Tuples.py): ordered, immutable sequences.
- [Sets](Sets.py): collections of unique values.
- [Dictionaries](Dictionaries.py): mappings from keys to values.

From the repository root:

```bash
python data_structures_algorithms/collections/Lists.py
```
